    Namespace caddyDns

    caddy-dns plugin integration

    Typed providerConfig builders for the caddy-dns/* ACME-DNS challenge provider modules — porkbun, cloudflare, route53, digitalocean, godaddy — layered on top of buildAcmeDnsPolicy (../caddy/acme.js), which only builds the wrapper shape and treats providerConfig as an opaque passthrough.

    See

    • https://github.com/caddy-dns
    • ../caddy/acme.ts

    Example

    import { buildAcmeDnsPolicy } from "@accelerated-software-development/caddy-api-client/caddy";
    import { buildAcmeDnsProviderConfig } from "@accelerated-software-development/caddy-api-client/plugins/caddy-dns";

    const { providerConfig } = buildAcmeDnsProviderConfig("cloudflare");
    const policy = buildAcmeDnsPolicy({
      subjects: ["example.com", "*.example.com"],
      dnsProvider: "cloudflare",
      providerConfig,
    });
